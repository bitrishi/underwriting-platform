Strategy 1: Basic RAG 1 LLM call — ~$0.001

The simplest RAG pipeline. Embed query, find similar chunks, send to LLM. No quality checking.

           │

  ┌─────────────────┐     ┌──────────────────────────────┐
  │ Similarity Search│────▶│  FAISS / OpenSearch           │

  │                  │◀────│  Returns top-3 by distance    │

Legal/regulatory queries (exact terms matter): weights [0.3, 0.7] favor keyword. Conceptual queries ("income requirements"): weights [0.7, 0.3] favor semantic. Default: [0.5, 0.5] balanced.

Strategy 6: Agentic RAG (Critical Compliance) 5-10 LLM calls — ~$0.005-0.010

Separate grading, optional query rewriting, generation from verified docs only, independent hallucination check. Maximum confidence.

  ┌──────────────────┐
  │ Critical Question  │  "Does this loan violate Texas Section 50(a)(6)?"
  └────────┬──────────┘
           │
           ▼
  ┌──────────────────────────────────────────────────────┐
  │  STEP 1: RETRIEVE (same as Strategy 5)                │
  │  Deterministic query + synonyms + metadata filter     │
  │  Returns 3 document chunks                            │
  │  (FREE — no LLM calls)                                │
  └────────┬──────────────────────────────────────────────┘
           │
           │  3 candidate documents
           ▼
  ┌──────────────────────────────────────────────────────┐
  │  STEP 2: GRADE EACH DOCUMENT SEPARATELY               │
  │  3 separate LLM calls — each grades ONE document      │
  │                                                       │
  │  LLM Call 1: "Is doc1 relevant to this question?"     │
  │    Doc1: "Max DTI is 43%..."                          │
  │    → {relevant: true, reasoning: "States DTI limit"}  │
  │                                                       │
  │  LLM Call 2: "Is doc2 relevant?"                      │
  │    Doc2: "Texas property tax rates vary..."           │
  │    → {relevant: false, reasoning: "About taxes, not   │
  │       DTI or Section 50(a)(6)"}                       │
  │                                                       │
  │  LLM Call 3: "Is doc3 relevant?"                      │
  │    Doc3: "Section 50(a)(6) LTV limit is 80%..."       │
  │    → {relevant: true, reasoning: "Directly addresses  │
  │       Section 50(a)(6) restrictions"}                 │
  │                                                       │

  │  judge relevance. No incentive to stretch relevance   │
  │  to produce an answer (unlike Strategy 5 where same   │
  │  LLM grades AND answers).                             │
  └────────┬──────────────────────────────────────────────┘
           │
           │  Filter: keep only relevant docs (2 of 3)
           │  Irrelevant doc2 REMOVED from context
           ▼

  │                                                       │

  │  ▼                                                    │

Strategy 7: Parent-Child Chunking 1 LLM call — ~$0.001

Search with small precise chunks, but send the larger parent chunk to the LLM for full context.

  ┌──────────────────────────────────────────────────────┐
  │ Original document section (2000 chars):               │
  │                                                       │
  │ "Section 3.4: DTI Requirements                        │
  │  The maximum DTI for qualified mortgages is 43%.      │
  │  However, borrowers with DTI between 41-43% require   │
  │  compensating factors. Compensating factors include:   │
  │  cash reserves exceeding 6 months, employment tenure  │
  │  over 5 years, or minimal increase in housing payment."│
  │                                                       │
  │ Chunked at 400 chars:                                 │
  │  Chunk A: "Section 3.4: DTI Requirements. The maximum │
  │           DTI for qualified mortgages is 43%. However,"│
  │  Chunk B: "borrowers with DTI between 41-43% require  │
  │           compensating factors. Compensating factors"  │
  │  Chunk C: "include: cash reserves exceeding 6 months, │
  │           employment tenure over 5 years..."          │
  │                                                       │
  │  Search "DTI compensating factors" hits Chunk B       │
  │  But Chunk B alone lacks: what ARE the factors (in C) │
  │  and what is the DTI limit (in A)                     │

  THE SOLUTION: SEARCH SMALL, READ BIG
  ┌──────────────────────────────────────────────────────┐
  │                                                       │
  │  PARENT chunk (2000 chars): Full section              │
  │  ┌─────────────────────────────────────────────────┐  │
  │  │ "Section 3.4: DTI Requirements. The maximum     │  │
  │  │  DTI for qualified mortgages is 43%. However,   │  │

  │  │  increase in housing payment."                   │  │
  │  └─────────────────────────────────────────────────┘  │
  │       │              │              │                  │
  │       ▼              ▼              ▼                  │
  │  ┌─────────┐   ┌─────────┐   ┌─────────┐             │
  │  │ Child A │   │ Child B │   │ Child C │  EMBEDDED    │
  │  │ 400char │   │ 400char │   │ 400char │  (for search)│
  │  │ DTI max │   │ comp.   │   │ reserves│              │
  │  │ is 43%  │   │ factors │   │ 6 months│              │
  │  └─────────┘   └────┬────┘   └─────────┘             │
  │                     │                                  │
  │    Search hits Child B (precise match!)                │
  │    But LLM receives PARENT (full context)              │
